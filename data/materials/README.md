# Material data

Refractive indices and complex permittivities used as inputs to every
simulation.

## Files

| File | What | Origin |
|---|---|---|
| `SS_permittivity.csv` | Stainless-steel complex permittivity ε(ν̃) over 400–7000 cm⁻¹ (≈ 1.43–25 µm). Symlink to `../../20260508_messages/SS_letter (1).csv` (the original Ane sent). | UPV/EHU SharePoint via Ane (2026-05-08) |
| `Cr2O3_HS_caliente.csv` | Cr₂O₃ refractive index n(λ), extinction coefficient k(λ) for **HS** films — heated substrate (300 °C). 200 points 3–25 µm. | Generated by Ane's `datos_cromo()` (test8.qmd) from Al-Kuhaili & Durrani (2007), HS parameters: a₀ = 0.010, a₁ = −0.04121, a₂ = 0.041509, E₀ = 5.13 eV, E_d = 19.2 eV |
| `Cr2O3_RS_frio.csv` | Cr₂O₃ (n, k) for **RS** films — unheated substrate. 200 points 3–25 µm. | Same model, RS parameters (in `20260508_messages/indices_cromo.csv`) |

## Caveats

> See [`../../ANALYSIS.md` §4](../../ANALYSIS.md) and §6.3 for a full
> discussion. In short:
>
> - Header of `SS_permittivity.csv` claims `wavenumber, n, k` but the
>   columns are actually `wavenumber, ε', ε''` (real and imaginary
>   permittivity, not refractive index). Code uses them as ε. Header is
>   misleading; values are right.
>
> - The Cr₂O₃ extinction-coefficient model is a sub-bandgap tail fitted
>   to 0.3–2.5 µm transmittance data. We use it from 3 to 25 µm — that
>   is **a 10× extrapolation outside its fit range**, and it contains
>   zero phonon physics (no Reststrahlen). The Tier-1 sweep includes a
>   categorical axis to swap dispersions; replacing this empirical tail
>   with literature ε(λ) is the largest physics upgrade available.

## How code reads them

`simulation/lib/sweep_runner.py` resolves these via:

```python
MAT_DIR = PROJECT_ROOT / "data" / "materials"
SS_PERMITTIVITY_CSV = MAT_DIR / "SS_permittivity.csv"
OXIDE_DISPERSIONS = {
    "HS_caliente": MAT_DIR / "Cr2O3_HS_caliente.csv",
    "RS_frio":     MAT_DIR / "Cr2O3_RS_frio.csv",
}
```
